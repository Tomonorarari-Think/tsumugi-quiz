立ち絵の表情を作るツール（つむぎクイズ）
========================================

公式の立ち絵（春日部つむぎ立ち絵_公式_v2.0.zip）から、ゲーム画面で使う場面ごとの表情 9 枚を
自分のパソコンで作るツールです。くわしい手順は、アプリのフォルダの manual\setup.html の
「6. 立ち絵を表示する」を見てください。

■ 必要なもの
- 公式の配布元から自分で入手した「春日部つむぎ立ち絵_公式_v2.0.zip」
- アプリ（TsumugiQuiz.exe）で、立ち絵の規約を含む利用規約に同意していること
- Python 3.10 以降（https://www.python.org/downloads/ から入れます）
- インターネット接続（手順 2 でライブラリをダウンロードするときだけ）

■ 手順
1. Python を入れる（初めてのときだけ）。
2. install-libraries.bat をダブルクリックする（初めてのときだけ。psd-tools と Pillow を入れます）。
3. アプリ（TsumugiQuiz.exe）を起動し、利用規約への同意画面で、立ち絵の規約を含むすべての規約に同意する
   （同意済みなら不要です。manual\setup.html の 3.3）。
   このとき、同意画面の立ち絵の規約と、立ち絵の zip の中の readme.txt を読んでおいてください。
   アプリで同意していないと、このツールは何も作らずに止まります（終了コード 5）。
   同意を撤回した場合や、アプリを新しくして規約が変わった場合も、もう一度同意してください。
4. 立ち絵の zip（展開しないまま）を、make-expressions.bat の上にドラッグ＆ドロップする。
   ダウンロード フォルダに zip があれば、make-expressions.bat をダブルクリックするだけでも動きます。
   フォルダ名やファイル名に & が入った場所からのドラッグ＆ドロップは、うまく渡らないことがあります
   （Windows のコマンドの制限）。そのときは zip をダウンロード フォルダに置いてダブルクリックしてください。
5. 「完了しました。」と出たら、アプリを起動し直す。

画像は次のフォルダに作られます（アプリが立ち絵を読む場所です）。
  %USERPROFILE%\AppData\LocalLow\Tomonorarari-Think\TsumugiQuiz\tsumugi\

■ 守ること（立ち絵の利用規約）
- 立ち絵の zip・PSD・PNG も、このツールで作った画像も、ほかの人に渡さないでください（二次配布の禁止）。
- 立ち絵の zip や作った画像を、このアプリのフォルダの中に置かないでください
  （アプリのフォルダごと人に渡したときに、一緒に渡ってしまいます）。
- このツールは、PSD にもとから入っている表情（目・口・眉・飾り）の表示を切り替え、
  バストアップの範囲を切り出して縮小するだけです。服装は変えません
  （制服が表示され、私服が表示されていないことを確かめてから書き出します）。
- 作業中は PSD を Windows の一時フォルダに取り出し、終わったら消します。

■ フォルダの中身（画像や PSD は入っていません）
  make-expressions.bat               表情を作る（ここに立ち絵の zip をドラッグ＆ドロップ）
  install-libraries.bat              ライブラリ（psd-tools・Pillow）を入れる
  make-expressions.ps1               上の 2 つから呼ばれる PowerShell のスクリプト
  tsumugi_expressions_standalone.py  立ち絵の zip から PSD を取り出し、保存先を決める
  tsumugi_app_consent.py             アプリでの同意の記録を確かめる
  generate_tsumugi_expressions.py    PSD から表情の画像を作る
  expressions.json                   どの表情にどのレイヤーを使うかの設定（レイヤーの名前だけ）
  requirements.txt                   入れるライブラリの一覧
  terms\                             アプリが表示する利用規約の本文（同意の記録と照らし合わせるのに使う）
